# 🌟 Production-Ready Playwright TypeScript Automation Framework

A scalable **End-to-End UI Automation Framework** developed using **Playwright**, **TypeScript**, and modern automation engineering best practices.

This project demonstrates how automation frameworks are designed for enterprise-level web applications with a focus on **maintainability**, **reusability**, **scalability**, and **continuous integration**.

The framework automates the **Sparkle Cart E-Commerce** application and showcases real-world testing scenarios commonly implemented by QA Automation Engineers and SDETs.

# ▶ Getting Started

## Clone Repository

```bash
git clone https://github.com/ArpitChoubey/Playwright-typescript-ecommerce-automation-framework.git
```

Move into project

```bash
cd Playwright-typescript-ecommerce-automation-framework
```

---

## Install Dependencies

```bash
npm install
```

---

## Install Playwright Browsers

```bash
npx playwright install
```

---

## Run All Tests

```bash
npx playwright test
```

---

## Run in UI Mode

```bash
npx playwright test --ui
```

---

## Run Specific Test

```bash
npx playwright test tests/<test-file>.spec.ts
```
